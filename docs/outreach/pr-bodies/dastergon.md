## Summary

Add [Chronos](https://github.com/sx4im/chronos) to **Notable Tools** (bottom of the category per contributing guidelines).

Chronos is a Deterministic Simulation Testing framework for Node.js/TypeScript with seeded network chaos (latency, drop, duplication, partitions) and crash injection. Failures replay bit-for-bit from a single seed — useful for chaos-style fault injection in simulated environments before production.

- Repo: https://github.com/sx4im/chronos
- Docs: https://docs-site-chronos.vercel.app/

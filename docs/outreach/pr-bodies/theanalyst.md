## Summary

Add [Chronos](https://github.com/sx4im/chronos) under **Verification of Distributed Systems**.

Chronos brings FoundationDB/TigerBeetle-style Deterministic Simulation Testing to Node.js and TypeScript: controlled time, seeded randomness, simulated network faults, and bit-identical replay from a single seed.

- Repo: https://github.com/sx4im/chronos
- Docs: https://docs-site-chronos.vercel.app/

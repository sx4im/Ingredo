## Summary

Add [Chronos](https://github.com/sx4im/chronos) to the **Software** section (alphabetically after Antithesis).

Chronos is a Deterministic Simulation Testing framework for **Node.js / TypeScript** — the JS/TS counterpart to MadSim / Turmoil / Tickloom. It provides a virtual clock, seeded PRNG, simulated network (latency / drop / dup / partition), crash/restart, Vitest integration, and bit-identical replay from a single seed.

- Repo: https://github.com/sx4im/chronos
- Docs: https://docs-site-chronos.vercel.app/

## Suggestion: add Chronos to Notable Tools

Hi — I'd like to suggest adding **[Chronos](https://github.com/sx4im/chronos)** to Notable Tools.

Chronos is Deterministic Simulation Testing for Node.js/TypeScript with seeded network chaos (latency, drop, duplication, partitions) and crash injection. Failures replay bit-for-bit from a single seed.

**Proposed entry** (bottom of Notable Tools):

```markdown
* [Chronos](https://github.com/sx4im/chronos) - Deterministic simulation testing for Node.js and TypeScript with seeded network chaos, partitions, and crash injection; bit-identical replay from a single seed.
```

Docs: https://docs-site-chronos.vercel.app/
